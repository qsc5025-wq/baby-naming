# 寶寶取名系統 V12

## GitHub Pages 部署
1. 建立 GitHub repository，例如 `baby-naming`。
2. 將 ZIP 內容上傳至 repository 根目錄。
3. Settings → Pages → Source 選 GitHub Actions。
4. 推送到 `main` 後由 workflow 自動部署。
5. 網址通常為 `https://你的帳號.github.io/baby-naming/`。
